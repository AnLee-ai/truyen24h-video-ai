# Vietnamese Comments Rule

Khi bạn tạo mới, chỉnh sửa, hoặc xem xét mã nguồn (code), bạn bắt buộc phải làm theo quy tắc sau:
- TẤT CẢ các comment (chú thích) trong code phải được viết bằng tiếng Việt.
- Điều này áp dụng cho mọi loại comment, bao gồm inline comments, block comments, docstrings, và function/method headers.
- KHÔNG sử dụng tiếng Anh hoặc ngôn ngữ khác cho các comment trong code trừ khi đó là các thuật ngữ chuyên ngành không thể dịch được một cách hợp lý.
- Code (tên biến, hàm, class, v.v.) có thể vẫn viết bằng tiếng Anh theo chuẩn chung, nhưng phần giải thích/chú thích phải bằng tiếng Việt.
